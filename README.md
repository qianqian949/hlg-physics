# HLG for Physics（进行中）

把一个原本用来分析 CS/ML 论文的工具（Hierarchical Logic Graph，分层逻辑图生成器），改造成能解释**物理公式为什么成立、什么时候会失效**的因果推理工具。

**这个项目不是** 生成物理习题答案的工具，而是想让AI讲清楚：一个物理公式背后的假设是什么、机制是什么、在什么条件下会失效。

> 项目处于早期阶段（第1周），当前内容是原始工具 + 早期测试记录，物理专用改造从第3周开始。完整6周计划见 [PROJECT_PLAN_30DAYS.md](PROJECT_PLAN_30DAYS.md)（压缩成30天执行）。

## 现状

- 沿用的原始工具：一个多论文对比分析器，上传2-5篇PDF，用智谱AI(GLM)模型提取每篇论文里的三层概念节点（研究问题/数学建模/技术方案），再分析概念之间的关系，最后做跨论文对比
- 已完成：环境验证、用8段物理解释文本做了首次人工核查测试
- 首次测试发现的问题记在 [day3_manual_review.md](day3_manual_review.md)：AI能提取出物理假设和失效条件，但会出现关系方向错误、关系类型选错、遗漏并列原因等问题；当前的分类体系（研究问题/数学建模/技术方案）本身是为CS论文设计的，套用到物理文本上比较别扭——这也是后续改造的方向
